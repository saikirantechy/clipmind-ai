## 🚀 Quick Start

### Prerequisites

- Python 3.9+
- pip (Python package manager)
- VideoDB API Key ([get one free](https://videodb.io))
- Google Gemini API Key ([get one free](https://makersuite.google.com/app/apikey))

### Installation

```bash
# 1. Clone or download this repository
cd clipmind-ai

# 2. Create a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
venv\Scripts\activate  # Windows

# 3. Install dependencies
pip install -r requirements_clipmind.txt

# 4. Configure environment variables
cp .env.example .env
# Edit .env and add your API keys:
# VIDEODB_API_KEY=your_videodb_key_here
# GEMINI_API_KEY=your_gemini_key_here
```

### Run the Backend

```bash
# Start the FastAPI server
python -m uvicorn clipmind:app --reload --port 8766

# Output should show:
# Uvicorn running on http://0.0.0.0:8766
# Application startup complete
```

### Open the Frontend

Open `frontend/clipmind.html` in your web browser, or:

```bash
# Serve with Python (if backend runs on different port)
python -m http.server 8000
# Visit http://localhost:8000/frontend/clipmind.html
```

## 🎬 API Endpoints

### Core Endpoints

#### 1. **POST /process** — Process a Video

Ingest a YouTube video and generate transcript + clips.

**Request:**

```json
{
  "url": "https://youtube.com/watch?v=...",
  "mode": "student" // student | creator | research
}
```

**Response:**

```json
{
  "success": true,
  "video_id": "vid_abc123",
  "video_title": "Video Title",
  "transcript_length": 5000,
  "clips_count": 12,
  "message": "Video processed successfully"
}
```

---

#### 2. **GET /search** — Search Transcript

Find moments matching your query.

**Request:**

```
GET /search?q=introduction&mode=student
```

**Response:**

```json
{
  "success": true,
  "query": "introduction",
  "clips": [
    {
      "text": "This is the introduction section...",
      "start": 0,
      "end": 45
    }
  ],
  "message": "Found 3 matching clips"
}
```

---

#### 3. **GET /reel** — Generate Reel

Create a shareable highlight reel.

**Request:**

```
GET /reel?mode=creator
```

**Response:**

```json
{
  "success": true,
  "stream_url": "https://...",
  "duration_seconds": 120,
  "clips_included": 8,
  "message": "Reel created successfully"
}
```

---

#### 4. **GET /summary** — AI Summary

Generate a Gemini-powered summary with bullet points.

**Request:**

```
GET /summary?mode=research
```

**Response:**

```json
{
  "success": true,
  "source": "gemini",
  "mode": "research",
  "bullets": ["Key finding 1: ...", "Key finding 2: ...", "Conclusion: ..."],
  "message": "Summary generated by Gemini"
}
```

---

#### 5. **GET /demo** — Demo Mode

Load pre-configured demo data (works offline).

**Request:**

```
GET /demo?mode=student
```

**Response:**

```json
{
  "success": true,
  "video_id": "demo_video",
  "video_title": "ClipMind AI Demo",
  "transcript": "...",
  "transcript_length": 2000,
  "clips": [...],
  "demo": true
}
```

---

#### 6. **GET /health** — Health Check

System status and configuration validation.

**Response:**

```json
{
  "success": true,
  "message": "ok",
  "videodb_api_key_present": true,
  "gemini_api_key_present": true
}
```

---

#### 7. **GET /status** — Current State

Get current processing state.

**Response:**

```json
{
  "video_id": "vid_abc123",
  "processing": false,
  "transcript_length": 5000,
  "clips_count": 12
}
```

---

#### 8. **POST /reset** — Reset State

Clear all processing state.

**Response:**

```json
{
  "success": true,
  "message": "State reset"
}
```

## 🛡️ Reliability & Fallbacks

ClipMind AI uses **5-level fallback chains** to ensure it never crashes:

```
1. Exact keyword search in transcript
   ↓ (if fails)
2. Semantic search across content
   ↓ (if fails)
3. Highlight extraction using mode-specific keywords
   ↓ (if fails)
4. Transcript slice sampling
   ↓ (if fails)
5. Synthetic/demo data template
   ✅ (always succeeds)
```

**Guarantees:**

- ✅ All endpoints return HTTP 200 (even on errors)
- ✅ All responses are valid JSON
- ✅ Never returns empty results (uses fallback data)
- ✅ 420-second processing timeout (prevents hanging)
- ✅ 30-second demo mode timeout (instant offline availability)
- ✅ Global exception handler (catches 100% of errors)

## 🔧 Configuration

### Environment Variables (.env)

```env
# VideoDB Configuration
VIDEODB_API_KEY=your_videodb_key_here

# Google Gemini Configuration
GEMINI_API_KEY=your_gemini_key_here

# Processing Configuration
TIMEOUT_SECONDS=420          # Max video processing time
LOG_LEVEL=INFO              # DEBUG | INFO | WARNING | ERROR
PORT=8766                   # Server port

# Optional: Pre-loaded demo video
VIDEODB_DEMO_VIDEO_ID=vid_xxx

INFO: Found 3 clips, returning results
WARNING: Demo mode engaged (live search failed)
ERROR: Gemini API error, using template summary
```

## 🐛 Troubleshooting

### "ModuleNotFoundError: No module named 'videodb'"

```bash
# Install missing dependencies
pip install -r requirements_clipmind.txt
```

### "VIDEODB_API_KEY not found"

```bash
# Check .env file exists and contains your key
cat .env

# Set manually (temporary)
export VIDEODB_API_KEY=your_key_here  # Linux/Mac
set VIDEODB_API_KEY=your_key_here     # Windows
```

### Frontend shows "Video Processing" forever

```bash
# Check backend is running
curl http://localhost:8766/health

# Check logs for errors
# Look for ERROR or WARNING messages

# Restart backend
python -m uvicorn clipmind:app --reload --port 8766
```

### API returns error message instead of results

✅ **This is normal!** ClipMind AI uses graceful degradation:

- Check the `fallback` field in response (`true` = fallback active)
- Check `source` field (`gemini` vs `template`)
- All results are still valid and usable

## 💡 Key Design Decisions

| Decision          | Rationale                                                  |
| ----------------- | ---------------------------------------------------------- |
