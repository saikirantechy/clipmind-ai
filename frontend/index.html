  • Happy path: Process URL → fullscreen “Processing…” → transcript fills → Search “important points” → timestamps + Play clip → Generate reel → AI summary.

  • If blocked: Browser DevTools → Network → failing /api/* call → screenshot response + uvicorn traceback.
